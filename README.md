一键安装

```
bash <(curl -fsSL https://raw.githubusercontent.com/hyp3365/tgweb/main/install.sh)
```

更新：已安装过再跑一次一键安装就是强制更新，也可以直接用 tg update。

```
bash <(curl -fsSL https://raw.githubusercontent.com/hyp3365/tgweb/main/install.sh) --force
tg update
```
